# Hex Nook Hop

Hex Nook 系列的极轻量 Windows 应用启动器。按 **Alt+Space** 呼出，输入拼音、首字母或英文，回车打开应用。

## 下载

[下载最新版安装包 HexNookHop-Setup.exe](https://github.com/15055334413le-ops/HexNook-Hop-Releases/releases/latest/download/HexNookHop-Setup.exe)

下载下来就是安装程序，双击即可安装，不需要管理员权限。各版本的更新说明见 [Releases](https://github.com/15055334413le-ops/HexNook-Hop-Releases/releases)。

## 卸载

在 Windows「设置 → 应用」里找到 Hex Nook Hop，点卸载。开机启动在「设置 → 应用 → 启动」里管理。
